The Linux shell (barg#) is on the screen. Keyboard: click the screen and type, or use the box above (it types the text for you, handy for pasting). Mouse: move and click over the screen. Everything takes a few seconds to show: one Linux tick is 100,000 simulated cycles. The screen shows the Linux framebuffer in the GPU's video memory.

Console (UART)

The shell prompt appears after roughly 200 million cycles. Verilator runs about 0.4 million cycles per second, so the boot takes several minutes.
